pbg-composite-nfsim-caspule

A process-bigraph composite that hands matter from a spatial bond-aware LAMMPS / CASPULE simulation into NFSim's non-spatial rule-based pool through a configurable ObservableDetector Step. Each simulator is configured by its own input file: a LAMMPS .in script, a BNGL .bngl model, and a detector .yaml rule list. Pick an experiment from the tabs below to inspect its time series, final spatial state, detector rules, and the full PBG document.

Architecture

Decoupled (baseline)

Detector outputs are routed to dead-end stores. Spatial CASPULE keeps every atom, NFSim never receives matter. Used as a baseline so the contribution of the bridge is visible by contrast in the other configurations.

caspule_interval = 0.05  |  nfsim_interval = 0.5  |  total_time = 5.0  |  decoupled = True

CASPULE input script (.in) 
# LAMMPS / CASPULE input — type-1 monomers diffuse and dimerize via
# `fix bond/create`. The dimer = a connected pair of type-1 atoms with
# one bond of type 1. Used by the composite as the "spatial dynamics"
# half of the simulation; the detector will pull dimers out of this
# pool and hand them to NFSim as a single Dimer molecule.
units lj
atom_style bond
boundary p p p
neighbor 0.5 bin
neigh_modify every 1 delay 0 check yes
region box block 0 8 0 8 0 8
create_box 1 box bond/types 1 extra/bond/per/atom 4 extra/special/per/atom 50
mass 1 1.0
lattice sc 1.6
create_atoms 1 box
pair_style soft 2.0
pair_coeff * * 30.0
bond_style harmonic
bond_coeff 1 5.0 1.5
minimize 1e-4 1e-4 100 100
fix nve all nve/limit 0.05
fix lan all langevin 0.4 0.4 1.0 12345
timestep 0.005
fix mkbnd all bond/create 1 1 1 1.8 1 iparam 1 1 jparam 1 1
thermo 5
NFSim model file (.bngl) 
# Non-spatial kinetics for the dimers handed off from CASPULE.
# A Dimer arrives in the pool, reversibly converts to an Active form,
# and Active dimers slowly degrade. Seed counts are exposed as named
# parameters (init_Dimer, init_Active) so NFSimProcess's regex-based
# count substitution has stable handles to bind to.
begin parameters
    init_Dimer    0
    init_Active   0
    k_activate    0.1
    k_deactivate  0.05
    k_decay       0.01
end parameters

begin molecule types
    Dimer()
    Active()
    Decay()
end molecule types

begin seed species
    Dimer()    init_Dimer
    Active()   init_Active
end seed species

begin observables
    Molecules Dimer    Dimer()
    Molecules Active   Active()
end observables

begin reaction rules
    Dimer() -> Active()    k_activate
    Active() -> Dimer()    k_deactivate
    Active() -> Decay()    k_decay
end reaction rules

Coupled (simple Dimer rule)

Default wiring with a single rule: bonded pairs of type-1 atoms (size exactly 2) are pulled out of the spatial pool and credited as Dimer molecules to NFSim. NFSim then runs the Dimer <-> Active -> Decay kinetics on the accumulated pool.

caspule_interval = 0.05  |  nfsim_interval = 0.5  |  total_time = 5.0  |  decoupled = False

Polymer fractionation (multi-rule)

A more interesting set-up. CASPULE allows up to four bonds per atom, so atoms grow into branched networks. The detector applies three rules: Dimer (size 2, removed), Trimer (size 3, removed) and Polymer (size 4+, observed but NOT removed). The non-spatial pool fills with size-bucketed species, while the spatial pool retains the polymer network — visible in the 3D view at the bottom of this tab.

caspule_interval = 0.05  |  nfsim_interval = 0.5  |  total_time = 5.0  |  decoupled = False

CASPULE input script (.in) 
# LAMMPS / CASPULE input — type-1 monomers polymerize into branched
# clusters. Each atom can carry up to 4 bonds (`iparam 4 1 jparam 4 1`),
# and bond formation is attempted every 10 timesteps so that clusters
# grow on a time-scale the detector can sample. Used as the spatial
# substrate for the multi-rule "polymer fractionation" experiment, where
# the detector pulls Dimers and Trimers into NFSim while leaving larger
# Polymer networks in the spatial pool for visualisation.
units lj
atom_style bond
boundary p p p
neighbor 0.5 bin
neigh_modify every 1 delay 0 check yes
region box block 0 6 0 6 0 6
create_box 1 box bond/types 1 extra/bond/per/atom 4 extra/special/per/atom 50
mass 1 1.0
lattice sc 1.6
create_atoms 1 box
pair_style soft 2.0
pair_coeff * * 30.0
bond_style harmonic
bond_coeff 1 5.0 1.5
minimize 1e-4 1e-4 100 100
fix nve all nve/limit 0.05
fix lan all langevin 0.4 0.4 1.0 12345
timestep 0.005
fix mkbnd all bond/create 10 1 1 1.8 1 iparam 4 1 jparam 4 1
thermo 5
NFSim model file (.bngl) 
# Non-spatial kinetics for the multi-rule polymer-fractionation demo.
# Each molecule arrives in the pool and decays through a different
# pathway: dimers activate quickly, trimers activate slowly, polymers
# decay slowly. All seed counts are exposed as named parameters so
# NFSimProcess's regex-based count substitution has stable handles.
begin parameters
    init_Dimer    0
    init_Trimer   0
    init_Polymer  0
    init_Active   0
    k_dimer_act   0.30
    k_trimer_act  0.05
    k_polymer_dec 0.02
    k_active_dec  0.05
end parameters

begin molecule types
    Dimer()
    Trimer()
    Polymer()
    Active()
    Decay()
end molecule types

begin seed species
    Dimer()    init_Dimer
    Trimer()   init_Trimer
    Polymer()  init_Polymer
    Active()   init_Active
end seed species

begin observables
    Molecules Dimer    Dimer()
    Molecules Trimer   Trimer()
    Molecules Polymer  Polymer()
    Molecules Active   Active()
end observables

begin reaction rules
    Dimer()   -> Active()    k_dimer_act
    Trimer()  -> Active()    k_trimer_act
    Active()  -> Decay()     k_active_dec
    Polymer() -> Decay()     k_polymer_dec
end reaction rules
